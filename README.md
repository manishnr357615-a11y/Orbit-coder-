🚀 Orbit Coder

Orbit Coder is a cyberpunk-themed AI chatbot web application designed to provide an interactive and modern AI experience.

✨ Features

- 🤖 AI-powered chatbot
- 🌌 Cyberpunk-inspired user interface
- 📱 Responsive design for mobile devices
- 💻 Dedicated chatbot interface
- 🎨 Custom HTML and CSS styling
- ⚡ Interactive JavaScript functionality
- 🌐 Deployed as a live web application

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chatbase
- Netlify

🎯 Project Goal

The goal of Orbit Coder is to create a modern AI-powered web experience while developing practical skills in frontend web development, AI integration, and web deployment.
